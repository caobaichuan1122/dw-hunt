# DW 打僵尸（DW Hunt）

[English](README.md) | **简体中文**

一个安卓无障碍应用，自动打《Dark War: Survival》里的丧尸。所有识别和点击都在手机/平板本机完成，不需要电脑，也不需要 root。

> **免责声明**：这是非官方项目，与游戏厂商无关。自动化操作可能违反游戏服务条款，导致账号受限。**使用风险自负。**

## 功能

- **两种目标**：巨型丧尸（集结，最高 Lv.35）或游荡丧尸（单人攻击，最高 Lv.40），每种目标单独设等级。
- **两种体力来源**：
  - **只用免费体力**：体力不足时只点绿色的免费"领取"（英雄免费体力和 125 体力补给）。领不到就暂停 10 分钟再试。
  - **用背包体力包**：体力不足时用背包里的体力包（每次 20 个），可设置最多用几个。
- **只用第一队**出兵，每次出兵前核对出兵框里选中的是不是第一队。
- 目标已被别人集结时，自动取消并重新搜索。
- **从不花钻石**：只会点免费领取和背包体力包，不会点任何"购买"按钮。
- **游戏语言**：简体中文、繁体中文、英文、韩文。「自动」跟随手机系统语言，也可以在设置里手动选（要和游戏里的语言一致）。
- 游戏内悬浮条：**▶** 开始，**■** 停止，**⚙** 随时改设置（不用退出游戏），**◂** 收起成小方块。

## 安装和使用

1. 安装 APK。安卓 13+ 的侧载应用需要先在"应用详情"右上角菜单里开启「允许受限制的设置」。
2. 系统设置 → 无障碍 → 打开「DW 打僵尸」。
3. 打开游戏，回到**世界地图**，点屏幕左上角悬浮条的 **▶**。
4. 点 **⚙** 选择目标、等级、体力来源和轮数。改动即时保存，下次点 ▶ 生效。

屏幕不是预期的样子时（比如没在世界地图上），脚本会停下，而不是乱点。

排查问题：日志通过 logcat 输出，标签是 `DWHunt`：`adb logcat -d -s DWHunt:I`。调试版还会写在应用私有目录的 `files/bot.log`。

## 兼容性

- 只在 **2000×2800 的平板**、游戏界面为**简体中文**时完整测试过。早期版本在手机上跑通过，但当前版本没有在手机上复测。
- 模板是游戏按钮的截图，所以游戏语言必须是应用带有模板的语言：简体中文（`templates/`）、繁体中文（`templates_tw/`）、英文（`templates_en/`）、韩文（`templates_ko/`）。应用里的语言要和游戏一致；如果游戏语言本来就跟手机系统语言一致，选「自动」即可。
- 繁体、英文、韩文在 1440×3168 的手机上测过。这三种语言还缺两张模板：免费体力对话框里绿色的「领取」按钮（所以只用免费体力模式下领不到，会提示没有免费体力），以及「目标正在被集结」对话框。
- 所有坐标以 2000×2800 为基准，再按屏幕高度等比缩放。缩放只能处理同样形状的大小屏幕，**处理不了长宽比不同**（游戏界面布局会变）。换设备大概率要重新截模板、调整部分坐标。
- 游戏更新改了界面后，模板可能失效。

## 工作原理

- `Device.kt`：用无障碍服务的 `takeScreenshot` 截屏，用 `dispatchGesture` 点击，用 OpenCV 做模板匹配和颜色统计。
- `Bot.kt`：打怪循环。搜索目标 → 集结或攻击 → 核对选中的是第一队 → 点行军 → 等第一队回家 → 下一轮。任何不符合预期的情况都会停下循环。
- `BotService.kt`：无障碍服务和悬浮条。`MainActivity.kt`：设置页。
- 模板放在 `app/src/main/assets/templates/`，文件名就是 `Bot.kt` 里 `find`、`findFast`、`pollFor` 用到的名字。

## 构建

需要 JDK 17 和 Android SDK（compileSdk 34，build-tools 35）。在项目根目录新建 `local.properties`：

```
sdk.dir=/path/to/Android/Sdk
```

然后：

```
./gradlew assembleDebug
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。

要出签名的 release 包：先生成密钥库，在项目根目录建一个不进 git 的 `keystore.properties`，再运行 `./gradlew assembleRelease`：

```
storeFile=/path/to/your.jks
storePassword=...
keyAlias=...
keyPassword=...
```

依赖：OpenCV 4.9.0（Maven）、kotlinx-coroutines。

## 增加其他游戏语言

带文字的按钮是模板，所以每种语言要各有一套。把重新截取的图放到 `app/src/main/assets/templates_<代码>/`（例如 `templates_tw/`），文件名和 `templates/` 里的一样；语言文件夹里没有的模板（图标，或两种语言写法相同的文字如「搜索」）会自动用 `templates/` 里的。再到 `Lang.kt` 里加上这种语言。

## 给其他设备重做模板

`templates/` 里每张图是一个界面元素（按钮、标题、标签）的截图。在新设备上截全屏图，裁出同一个元素，用同样的文件名保存即可。如果长宽比不同，还要检查 `Bot.kt` 里的基准坐标。
